Chat Widget Integration Test

Test Instructions

  1. Ensure the server is running: cd server && npm run dev
  2. Look for the chat widget in the bottom-right corner
  3. Click the chat button to open the widget
  4. Try sending a message
  5. Verify the AI responds (requires OPENAI_API_KEY set in .env)
Note: If you see "OpenAI API key is not configured" in the chat, make sure you've set OPENAI_API_KEY in your .env file.
